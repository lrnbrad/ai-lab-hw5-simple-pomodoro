# Domain Docs

Engineering skills should read `CONTEXT.md` at the repository root and relevant ADRs under `docs/adr/` before exploring or changing the codebase.

If those files do not exist, proceed without flagging their absence. Create them lazily only when domain terms or architectural decisions are actually established.

This is a single-context repository:

- `CONTEXT.md` contains shared domain vocabulary.
- `docs/adr/` contains system-wide architecture decisions.
